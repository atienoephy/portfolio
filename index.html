About

The short version, and the stack behind it.

I'm currently training at Zone01 Kisumu, a peer-to-peer coding school, where most projects are built from a spec, in Go, without a framework to lean on. That's taught me to read requirements closely and ship things that pass the tests, not just look right.

Outside school projects I build my own tools end to end — picking the problem, writing the code, and shipping it somewhere real. Currently learning how the pieces fit together: server code, templates, REST endpoints, and plain HTML/CSS/JS on the front end.

ascii-art-web

A Go web server that turns text into ASCII art banners — shadow, standard, and thinkertoy styles — through a browser UI instead of the command line.
